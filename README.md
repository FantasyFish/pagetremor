## ✨ 功能特色

| | |
|:---|:---|
| 🎯 **三类监测目标** | HTML 网页（CSS / XPath 选择器）、RSS 订阅源、JSON API（JSONPath），覆盖绝大多数场景 |
| 🖱️ **元素拾取器** | 在目标网页上点一下要监测的内容，选择器自动生成；一键验证即时高亮确认，无需懂代码 |
| 🪜 **多级内容读取策略** | 直接读取、标签页读取、动态滚动、页面 JSON 响应候选识别，动态网页也能尽量拿到真实内容 |
| 🔍 **精准 Diff 对照** | 每次检测与上次快照自动对比，"变更前 / 变更后"一眼看清改了哪几个字 |
| 🧹 **获取前预处理** | 点击、填写、选择、滚动、等待等动作，先点掉 Cookie 弹窗、展开折叠内容再读取 |
| 🔔 **多渠道通知** | 桌面通知、声音、钉钉、企业微信、飞书、Telegram、自定义 Webhook |
| 🤫 **免打扰静默时段** | 设定免打扰窗口，半夜的变化早上再看 |
| 🧪 **过滤规则** | 关键词、正则、数字比较等匹配与排除规则，只提醒真正关心的变化 |
| 📒 **全链路日志** | 任务检测日志、通知日志、诊断日志三页签，调度、读取、对比、发送每一步有迹可循 |
| 🔒 **本地优先** | 任务、快照、日志默认保存在浏览器本地，不上传监测内容，不做使用统计 |

## 🚀 快速上手

1. 安装扩展后，点击工具栏图标打开弹窗，点 **🎯 拾取** 圈选要监测的网页区域；
2. 设置检测间隔与通知方式，保存任务；
3. 内容变化时，通知自动送达 —— 从此告别手动刷新。

## 🛡️ 使用边界

只监测你**有权访问**的内容；本扩展遇到人机验证只会如实诊断并提醒你手动处理，
不会、也不会帮助你绕过任何网站的访问控制。完整说明见[合规使用指南](https://pagetremor-site.pages.dev/guide.html)。
